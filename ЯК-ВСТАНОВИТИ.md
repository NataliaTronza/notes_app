# Клаптик — як поставити на телефон

У папці лежать:

```
index.html
manifest.json
sw.js
icons/
```

Усі вони мають лежати **разом, в одній теці** — інакше не буде ні іконки, ні офлайну.

## Встановлення (GitHub Pages, як у «Диханні»)

Установлення вимагає адреси `https://` — з локального файлу браузер пропонує лише
«зберегти посилання», без власної іконки.

1. Створи репозиторій, наприклад `klaptyk`, і завантаж туди весь вміст цієї папки
   (разом з текою `icons/`).
2. Settings → Pages → Branch: `main`, папка `/ (root)` → Save.
3. За хвилину сторінка буде за адресою `https://<твій-нік>.github.io/klaptyk/`.
4. Відкрий цю адресу в Chrome на телефоні. У шапці застосунку зʼявиться кнопка
   **«＋ встановити застосунок»** — тисни її. Або меню ⋮ → «Додати на головний екран».

На iPhone: Safari → «Поділитися» → «На екран Домівки». Кнопки «Встановити» там немає,
це особливість Safari.

Після встановлення «Клаптик» стоїть окремою іконкою з рожевим серцем, відкривається на
весь екран без адресного рядка і **працює без інтернету**.

## Якщо захочеш оновити застосунок

Коли я зроблю нову версію:

1. Заміни файли на хостингу.
2. У `sw.js` зміни рядок `CACHE_VERSION = "klaptyk-v1"` на `v2`
   (інакше телефон показуватиме стару версію з памʼяті).
3. На телефоні закрий застосунок і відкрий знову.

Нотатки при оновленні залишаються на місці — вони зберігаються окремо, у памʼяті
пристрою. Синхронізації між пристроями немає.
