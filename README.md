# Клаптик — як поставити на телефон

У папці кілька файлів. Вони мають лежати **разом, в одній теці** — інакше не буде ні іконки, ні офлайну.

```
index.html
manifest.json
sw.js
icons/
```

## Спосіб 1 — встановити як застосунок (рекомендую)

Установлення вимагає адреси `https://`, тому файли треба один раз десь покласти. Підійде той самий GitHub Pages, де вже живе «Дихання» і твої уроки.

1. Створи репозиторій, наприклад `klaptyk`, і завантаж туди всі файли з цієї папки (разом з `icons/`).
2. Settings → Pages → Branch: `main`, папка `/ (root)` → Save.
3. За хвилину сторінка буде за адресою `https://<твій-нік>.github.io/klaptyk/`.
4. Відкрий цю адресу в Chrome на телефоні. Знизу з'явиться пропозиція встановити, або меню ⋮ → «Додати на головний екран».

Після цього застосунок стоїть окремою іконкою, відкривається на весь екран без адресного рядка і **працює без інтернету** — усе закешовано.

На iPhone: Safari → кнопка «Поділитися» → «На екран Домівки». Кнопки «Встановити» там немає, це особливість Safari.

### Коли міняєш файли

Телефон тримає стару копію в кеші. Щоб оновлення приїхало, підніми версію в `sw.js`:

```js
const CACHE = 'klaptyk-v2';   // було v1
```

## Спосіб 2 — просто відкрити файл

Скинути `index.html` на телефон і відкрити з «Файлів» через Chrome. Застосунок працюватиме, але без встановлення — Chrome не бачить `manifest.json`/`sw.js` з локального файлу, тому пропонує лише «зберегти посилання», без власної іконки.
